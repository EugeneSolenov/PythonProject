# Семейный календарь — ПР3

## Назначение

Консольное приложение для хранения событий нескольких пользователей. В ПР3 функциональная модель ПР2 переработана в объектную модель: данные и поведение объединены в классах `User` и `Event`.

## Объектная модель

### `Event`

Класс события содержит атрибуты:

- `name` — название;
- `event_date` — дата;
- `category` — категория;
- `is_completed` — признак выполнения.

Методы:

- `__init__()` — создание объекта;
- `__str__()` — строковое представление;
- `days_until()` — число дней до события;
- `is_upcoming()` — проверка актуальности;
- `mark_completed()` — отметка события выполненным;
- `to_dict()` и `from_dict()` — преобразование для JSON.

### `User`

Класс пользователя содержит `user_id`, `name` и коллекцию `events: list[Event]`.

Методы `add_event()`, `remove_event()`, `find_event()` и `upcoming_events()` организуют взаимодействие пользователя с объектами событий. Таким образом, пользователь хранит объекты `Event`, а не словари.

## Модули

- `main.py` — консольный интерфейс и пользовательские сценарии;
- `models.py` — классы `User` и `Event`;
- `calendar_service.py` — функции обработки коллекций объектов;
- `storage.py` — загрузка и сохранение объектов в JSON;
- `data/events.json` — постоянное хранилище;
- `tests/` — автоматизированные тесты объектной модели;
- `test_main.py` — сохранённые тесты базового сценария ПР1.

## JSON-хранилище

Данные хранятся в `data/events.json`. При загрузке JSON преобразуется в коллекцию `list[User]`, а вложенные записи — в объекты `Event`. При сохранении объекты преобразуются обратно в JSON-совместимые словари.

Хранилище поддерживает также прежний формат ПР2 `имя пользователя → список событий`, поэтому данные предыдущей работы не теряются.

## Запуск

```text
python main.py
```

Меню позволяет добавлять, просматривать, удалять и отмечать события выполненными, а также переключать пользователей.

## Проверка

```text
python -m pytest -q
python -m flake8
python -m compileall -q .
```

Тесты проверяют конструкторы и атрибуты классов, `__str__`, методы событий и пользователей, сортировку, обработку дат, сериализацию JSON, ошибки повреждённого файла и совместимость с функциональностью ПР2.
