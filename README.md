# Семейный календарь

## Назначение

«Семейный календарь» — простое консольное приложение для добавления семейных событий и напоминаний о них.

## Целевая аудитория

Проект предназначен для членов семьи, которым нужно сохранять даты личных и семейных событий.

## Описание предметной области

Семейный календарь содержит пользователей и связанные с ними события. Каждое событие имеет название и дату. После добавления событий пользователь может завершить ввод, а приложение выводит весь список и сообщает, сколько дней осталось до каждого события, произошло ли оно сегодня или уже прошло.

## Основные сущности

- Пользователь — человек, который использует календарь.
- Семья — группа пользователей, объединённых общими событиями.
- Событие — важная дата с названием.
- Напоминание — сообщение о состоянии события.

## Основные функции

- ввод имени пользователя;
- добавление нескольких событий;
- ввод названия события;
- ввод даты события в формате `ДД.ММ.ГГГГ`;
- вывод всех добавленных событий без завершения работы;
- возврат в главное меню после просмотра событий;
- смена пользователя через главное меню;
- вычисление количества дней до события;
- вывод напоминания о событии;
- отдельный выход из приложения.

## План развития проекта

1. Добавить хранение событий в файле.
2. Реализовать сохранение отдельных списков событий для разных пользователей.
3. Добавить изменение и удаление событий.
4. Добавить сортировку событий по датам.
5. Создать отдельные функции для основных операций.
6. Создать графический интерфейс и хранение данных в базе данных.

## Тестирование

Для запуска автоматических тестов установите `pytest`, если он ещё не установлен:

```text
python -m pip install pytest
```

После этого запустите тесты из папки проекта:

```text
python -m pytest -q
```

Тесты в [`test_main.py`](test_main.py:1) проверяют добавление события, преобразование даты, вывод пустого списка, вывод события и обработку некорректной даты.

## Отладка

Для отладки в VS Code точку останова можно установить на строке с вычислением `days_left` в файле [`main.py`](main.py:23). После запуска программы в режиме Debug выполняется пошаговый переход по строкам. В окне переменных проверяются значения `user_name`, `events`, `event_name`, `event_date`, `today` и `days_left`.

## Функции программы

- [`add_event()`](main.py:4) запрашивает название и дату события, преобразует дату и добавляет событие в список.
- [`show_events()`](main.py:12) выводит события пользователя и рассчитывает напоминание для каждого события.

Повторяющиеся операции вынесены в отдельные функции, чтобы основной цикл меню отвечал только за выбор действия и переход между режимами приложения.

Для учебной проверки заранее можно заменить формат даты `"%d.%m.%Y"` на ошибочный формат. При вводе даты, например `08.09.2026`, программа завершится с ошибкой преобразования даты. Причина ошибки — формат в [`datetime.strptime()`](main.py:20) не соответствует формату введённой даты. После исправления формат возвращается к `"%d.%m.%Y"`, и программа продолжает работу.

Пример сценария:

1. Ввести имя пользователя `Анна`.
2. Выбрать действие `1` и добавить событие `День рождения` с датой `08.09.2026`.
3. Выбрать действие `1` и добавить событие `Новый год` с датой `31.12.2099`.
4. Выбрать действие `2`.
5. Просмотреть все события и напоминания.
6. Нажать Enter, чтобы вернуться в меню.
7. Выбрать действие `3` и ввести имя нового пользователя.
8. Выбрать действие `2`, чтобы увидеть список событий нового пользователя.
9. Выбрать действие `4` для закрытия приложения.

При смене пользователя текущий список событий очищается, потому что в начальной версии приложение не хранит данные между пользователями.
