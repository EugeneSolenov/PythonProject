# Семейный календарь

## Назначение

«Семейный календарь» — консольное приложение для хранения событий разных пользователей и напоминаний о важных датах. Проект расширяет сценарий ПР1: исходные функции ввода и показа событий сохранены, а данные переведены на модели и JSON-хранилище.

## Структура проекта

- [`main.py`](main.py) — консольное меню и совместимые функции сценария ПР1.
- [`models.py`](models.py) — структура данных [`Event`](models.py:12) и преобразование в JSON.
- [`calendar_service.py`](calendar_service.py) — функции добавления, удаления, сортировки и расчёта статуса событий.
- [`storage.py`](storage.py) — загрузка и сохранение коллекций пользователей в JSON.
- [`data/events.json`](data/events.json) — файл данных приложения.
- [`tests/test_calendar.py`](tests/test_calendar.py) — тесты сервисов и хранилища.
- [`test_main.py`](test_main.py) — тесты исходных функций ПР1.

## Возможности

- добавление события с датой в формате `ДД.ММ.ГГГГ`;
- просмотр событий пользователя с расчётом напоминания;
- сортировка событий по датам;
- удаление события по названию;
- отдельные списки событий для разных пользователей;
- сохранение и загрузка данных в JSON;
- обработка некорректных дат, повреждённого JSON и ошибок файловой системы.

## Использованные конструкции ПР2

- структуры данных: [`Event`](models.py:12), списки и словари;
- функции с документацией и аннотациями типов;
- циклы для обхода наборов событий;
- разбиение на логические модули;
- исключения [`StorageError`](storage.py:12) и `ValueError`;
- контекстный менеджер [`with`](storage.py:21) при работе с файлами;
- сериализация JSON и тестирование через pytest.

## Запуск

```text
python main.py
```

Приложение создаёт или обновляет [`data/events.json`](data/events.json). При смене пользователя его события загружаются из общего хранилища, а не теряются, как в первоначальной версии.

## Тестирование и линтер

Установка зависимостей:

```text
python -m pip install pytest flake8
```

Запуск тестов:

```text
python -m pytest -q
```

Проверка оформления:

```text
flake8
```

Ожидаемый результат `flake8` — отсутствие сообщений.

## Пример сценария

1. Запустить [`main()`](main.py:74).
2. Ввести имя пользователя `Анна`.
3. Выбрать `1` и добавить событие `День рождения` с датой `31.12.2099`.
4. Выбрать `2` для просмотра напоминаний.
5. Выбрать `3` для удаления события или `4` для смены пользователя.
6. Выбрать `5` для завершения работы.
